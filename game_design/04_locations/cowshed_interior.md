# 플레이어의 외양간
- 집 주인 : 플레이어

## 기본 기능

- 돼지나 소를 기를 수 있음.

---

## 맵 설명
맵에는 4칸의 외양간 자리가 있으며, 각 칸 마다 돼지나 소를 1마리씩 키울 수 있음.
(플레이어는 최대 4마리까지 기를 수 있음.)

---

# Object Layer
Tiled에 제작된 Object Layer 설명

## Warp
* cowshed_out : 외양간 밖으로 이동

## Spawn
* cowshed_enterance : 플레이어가 외양간 안으로 이동했을 때, 생성되는 위치

## Interactable
* door1_open : 첫번째 칸의 문을 연다.
* door2_open : 두번째 칸의 문을 연다.
* door3_open : 세번째 칸의 문을 연다.
* door4_open : 네번째 칸의 문을 연다.
