## Warp

* home_in_plaza4 : plaza4.tmx에서 Home.tmx로 이동하는 지점.
* plaza5_in_plaza4 : plaza4.tmx에서 plaza5.tmx로 이동하는 지점.
* plaza2_in_plaza4 : plaza4.tmx에서 plaza2.tmx로 이동하는 지점.
* temple_in : plaza4.tmx에서 temple_interior.tmx로 이동하는 지점.
* general_store_in : plaza4.tmx에서 general_interior.tmx로 이동하는 지점.

## Spawn

* plaza4_enterance_home : Home.tmx에서 plaza4.tmx로 이동 시 스폰 되는 지점.
* plaza4_enterance_plaza2 : plaza2.tmx에서 plaza4.tmx로 이동 시 스폰 되는 지점.
* plaza4_enterance_plaza5 : plaza5.tmx에서 plaza4.tmx로 이동 시 스폰 되는 지점.
* plaza4_standing : plaza4.tmx에서 NPC가 절 근처에 서있는 지점.
* plaza4_pond_sitting : plaza4.tmx에서 NPC가 잡화점 근처 분수대 벤치에 앉아있는 지점.
* temple_exit : temple_interior.tmx에서 plaza4.tmx로 이동 시 스폰 되는 지점.
* general_exit : general_interior.tmx에서 plaza4.tmx로 이동 시 스폰 되는 지점.

- NPC들은 맵을 이동시 Warp와 Spawn 지점을 이용하며, 종종 Warp와 관련 없는 Spawn 지점에 서 있기도 한다.
