## Warp

* home_in_plaza1 : plaza1.tmx에서 Home.tmx로 이동하는 지점.
* plaza2_in_plaza1 : plaza1.tmx에서 plaza2.tmx로 이동하는 지점.
* plaza3_in_plaza1 : plaza1.tmx에서 plaza3.tmx로 이동하는 지점.
* police_office_in : plaza1.tmx에서 police_interior.tmx로 이동하는 지점.
* hospital_in : plaza1.tmx에서 hospital_interior.tmx로 이동하는 지점.
* furniture_in : plaza1.tmx에서 furniture_interior.tmx로 이동하는 지점.

## Spawn

* plaza1_enterance_home : Home.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.
* plaza1_enterance_plaza2 : plaza2.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.
* plaza1_enterance_plaza3 : plaza3.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.
* plaza1_police_office_standing : plaza1.tmx에서 NPC가 경찰서 앞에 서있는 지점.
* plaza1_flower_standing : plaza1.tmx에서 NPC가 꽃밭 옆에 서있는 지점.
* plaza1_pond_sitting : plaza1.tmx에서 NPC가 분수대 앞 벤치에 앉아있는 지점.
* hospital_exit : hospital_interior.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.
* police_office_exit : police_interior.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.
* furniture_exit : furniture_interior.tmx에서 plaza1.tmx로 이동 시 스폰 되는 지점.

## NPC

- NPC들은 맵을 이동시 Warp와 Spawn 지점을 이용하며, 종종 Warp와 관련 없는 Spawn 지점에 서 있기도 한다.
