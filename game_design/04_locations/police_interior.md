# 경찰서
- 집 주인 : 폴리(poli)

## 기본 기능

- 플레이어는 경찰서를 방문하여 종종 폴리와 이야기를 나눌 수 있다.

---

# Object Layer
Tiled에 제작된 Object Layer 설명

## Warp
* police_office_out : 경찰서 밖으로 이동

## Spawn
* police_office_enterance : 플레이어가 경찰서 안으로 이동했을 때, 생성되는 위치
* police_working : 집의 주인이 서 있는 위치.
* police_standing : 집의 주인(폴리)의 두 번째 위치
