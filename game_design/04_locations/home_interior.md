# 플레이어 집

## 기본 기능

- 침대 (취침)
- 컴퓨터 (이메일)
- 책장 (추억의 물건 도감)
- 장식 배치

---

## 책장

플레이어는 집의 책장을 통해 추억의 물건 도감을 확인할 수 있다.

책장은 게임 내 메뉴가 아닌 월드 오브젝트이다.

플레이어가 책장을 조사하면 도감 UI가 열린다.

획득하지 않은 추억의 물건은 도감에 등록되지 않아 보이지 않는다.

### 확인 가능 정보
- 획득한 추억의 물건
- 설명
- 획득 날짜

---

## 컴퓨터

플레이어는 컴퓨터를 통해 npc와 이메일을 주고 받을 수 있다.
컴퓨터를 켜면 바탕화면에 e-mail 바로가기 아이콘이 있다.
그 아이콘을 클릭하면 e-mail 창에 들어갈 수 있다.
e-mail 창은 수신 메일함 탭, 발신 메일함 탭, 메일 쓰기 탭이 있다.

플레이어는 하루에 한번 메일쓰기 탭에서 NPC 레스토랑 초대, NPC에게 메일 발송을 할 수 있다.

# Object Layer
Tiled에 제작된 Object Layer 설명

## Warp
* home_out : 플레이어의 집 밖으로 이동

## Spawn
* home_enterance : 플레이어가 집 안으로 이동했을 때, 생성되는 위치

## Interactable
* sleep : 플레이어가 해당 위치와 상호작용 시, 잠에 듦.
* collection : 플레이어가 해당 위치와 상호작용 시, 도감 창을 띄워줌.
* computer : 플레이어가 해당 위치와 상호작용 시, 컴퓨터의 이메일 창을 띄워줌.
