## Warp

* plaza1_in_plaza2 : plaza2.tmx에서 plaza1.tmx로 이동하는 지점.
* plaza4_in_plaza2 : plaza2.tmx에서 plaza4.tmx로 이동하는 지점.
* pasture_in : plaza2.tmx에서 pasture_interior.tmx로 이동하는 지점.
* bookstore_in : plaza2.tmx에서 book_interior.tmx로 이동하는 지점.
* farm_in : plaza2.tmx에서 farm_interior.tmx로 이동하는 지점.

## Spawn

* plaza2_enterance_plaza1 : plaza1.tmx에서 plaza2.tmx로 이동 시 스폰 되는 지점.
* plaza2_enterance_plaza4 : plaza4.tmx에서 plaza2.tmx로 이동 시 스폰 되는 지점.
* farm_standing : plaza2.tmx에서 농장 가게 NPC가 밭 옆에 서있는 지점.
* book_standing : plaza2.tmx에서 서점 NPC가 나무 밑에 서있는 지점.
* farm_exit : farm_interior.tmx에서 plaza2.tmx로 이동 시 스폰 되는 지점.
* book_exit : book_interior.tmx에서 plaza2.tmx로 이동 시 스폰 되는 지점.
* pasture_exit : pasture_interior.tmx에서 plaza2.tmx로 이동 시 스폰 되는 지점.
