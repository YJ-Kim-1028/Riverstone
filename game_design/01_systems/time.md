# Time System

## 개요

시간은 게임의 모든 시스템을 제어하는 핵심 요소이다.
다음 시스템은 TimeManager를 통해 관리한다.

* NPC 스케줄
* 레스토랑 영업
* npc별 전용 건물 방문
* 이메일 도착
* 이벤트 발생
* 살인 사건
* 취침
* 날짜 및 요일 변경

---

## 시간 규칙

### 하루

* 시작 시간 : 09:00
* 종료 시간 : 24:00
* 24:00 가 되면 강제 취침한다.
* 플레이어가 취침 시간이 될 때까지 야외에 있을 경우, 길바닥 기절 후 다음 날 디버프를 얻는다.

---

### 시간 흐름

* 현실 시간 1초 = 게임 시간 1분
* 게임 시간 60분 = 현실 시간 60초

---

## 시간 포맷

게임 내부에서는 24시간 형식을 사용한다.

예시:

* 09:00
* 10:30
* 14:20
* 23:50

---

## 하루 진행

| 시간    | 이벤트        |
| ----- | ---------- |
| 09:00 | 기상         |
| 10:00 | 레스토랑 영업 가능 |
| 16:00 | 레스토랑 영업 종료 |
| 22:00 | 야간 이벤트 가능  |
| 24:00 | 강제 취침      |

---

## 날짜 시스템

하루가 종료되면 날짜가 증가한다.

예시:

* Day 1
* Day 2
* Day 3

---

## 계절

*계절은 존재하지 않는다.

---

## NPC 스케줄

모든 NPC는 시간 기반 스케줄을 가진다.

예시:

```json
{
    "09:00": "home",
    "10:00": "town",
    "14:00": "restaurant",
    "20:00": "home"
}
```

---

## 살인 시스템

스토커는 시간 조건을 만족할 때만 행동할 수 있다.

예시:

* 오후 10시
* 플레이어와 피해자&스토커 NPC의 맵이 겹치지 않을 때
* 특정 NPC가 생존 중일 때
* 비가 오는 날

세부 조건은 `../02_horror/murder_system.md`를 참조한다.

---

## 저장

저장 시 반드시 아래 정보를 기록한다.

* 현재 날짜
* 현재 시간
* 현재 요일
* 날씨

---

## TimeManager 책임

TimeManager는 다음 기능만 담당한다.

* 시간 증가
* 날짜 증가
* 시간 이벤트 발행

NPC 이동, 레스토랑 운영, 이벤트 실행은 각 시스템이 담당한다.

---

## 설계 목표

* 하루의 선택이 의미를 갖도록 한다.
* NPC가 살아 있는 것처럼 느껴지도록 한다.
* 평화로운 일상 속에서 불안감을 자연스럽게 조성한다.
