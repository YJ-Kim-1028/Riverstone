# Day 7 개발 현황 정리

`day6.md`에 이어지는 문서. 오늘은 발소리(Path/Ground 경계 버그) 수정, 연못 소리 볼륨 재조정, 플레이어 좌우 걷기 애니메이션이 "안 바뀌어 보이는" 문제의 원인 조사, 이렇게 세 가지를 다뤘다. 코드 변경은 `scripts/player/player.gd`, `scripts/autoload/audio_manager.gd` 두 파일에 걸쳐 있다. 마지막에는 `day6.md`에서 이어받은 누적 TO-DO 리스트 중 다수 항목(축산 시스템, 선물/상점 가격, 볼륨 설정 메뉴, 구 빗소리 삭제, 효과음 반영)이 실제로는 이미 완료돼 있던 걸 사용자 제보로 코드/데이터를 다시 확인해서 리스트를 정리했다.

---

## 1. 오늘 완료한 것

### 1-1. 발소리 - Path/Ground 경계에서 소리가 이상하게 끊기던 문제
- **증상**: Path 타일을 한 칸만 놔둔 곳처럼 Ground/Path 경계를 왔다갔다할 때 발소리가 이상하게 반복/끊김
- **원인**: `AudioManager._update_footstep_sfx()`가 매 프레임 `player.position`으로 타일 표면을 다시 판정해서, 경계에서 위치가 프레임마다 Path/Ground로 뒤집히면 그때마다 재생 중이던 클립을 강제로 끊고 다른 클립을 처음부터 재생 - 클립이 끝까지 못 나오고 계속 잘림
- **1차 임시 조치(사용자 지시)**: 지금 Path 발소리 자체가 별로라 흙 발소리 에셋을 나중에 찾을 때까지 Path도 Ground와 같은 소리(`SFX_GROUND_FOOTSTEP`)를 재생하도록 임시 교체(`audio_manager.gd`, TODO 주석 남김 - 흙 발소리 확보되면 `SFX_FOOTSTEP`으로 되돌릴 것)
- **근본 수정**: 매 프레임 위치를 검사하는 대신, `player.gd`의 걷기 애니메이션 프레임 토글 시점(`WALK_FRAME_INTERVAL`=0.35초마다, 발이 땅에 닿는 박자)에만 표면을 검사해서 한 번 재생하도록 구조 변경
  - `player.gd`: `footstep` 신호 신규 추가, 걷기 프레임 토글되는 순간 emit
  - `audio_manager.gd`: `set_player()`에서 `footstep` 신호 연결, 매 프레임 폴링하던 `_update_footstep_sfx()` 제거 → 신호 수신 시 1회 재생하는 `_on_player_footstep()`/`_play_footstep_once()`로 교체
  - 효과: 타일 경계에서 위치가 흔들려도 걸음 박자 단위로만 검사하므로 떨림 없음, 발소리도 실제 걷기 애니메이션과 정확히 맞아떨어짐
- **후속 버그 발견/수정**: 위 구조로 바꾼 뒤 "멈췄는데도 발소리가 이어서 들리는" 문제 발생 - 걸음 박자에 트리거만 걸고 정지 시 끄는 로직을 안 넣었던 게 원인. `_process()`에 "이동 중이 아니면 두 발소리 플레이어 모두 stop" 체크를 다시 추가해서 해결(이건 `is_moving()` 하나만 보는 안정적인 조건이라 경계 떨림 버그가 재발하지 않음)

### 1-2. 연못 소리(`sfx_pond`) 볼륨 재조정
- 기존 `-7.5dB`(원본 대비 진폭 약 42%, 약 58% 감소)가 너무 작다는 피드백
- 1차: "원본보다 20%만 줄여줘" → 선형 진폭 0.8 기준 `20*log10(0.8) ≈ -1.94dB`로 변경
- 최종: 그마저도 빼고 감쇠 없이 **원본 그대로(0dB)** 로 확정(`POND_SFX_TARGET_VOLUME_DB`)

### 1-3. 플레이어 좌우 걷기 애니메이션 "안 바뀌어 보이는" 문제 - 원인 조사
- **증상**: 짧게 걸을 때뿐 아니라 멀리 걸어도 좌/우 방향에서 그림이 안 바뀌는 것처럼 보임(위/아래는 정상)
- **원인 확인**: 코드 버그가 아니라 스프라이트시트 자체의 한계. `npc_sprite.gd` 주석에 이미 "좌/우 전용 정지 프레임이 없어서 걷기 프레임(3, 5)을 그대로 정지 포즈로 재사용한다(기획자 확인 완료)"고 명시되어 있음 - 좌/우로 걸으면 "정지 포즈처럼 보이는 프레임 ↔ 다른 걷기 프레임"을 반복해서, 위/아래(두 프레임이 서로 다름)와 달리 절반은 멈춘 것처럼 보임. `player.gd`는 정식 스프라이트가 아직 없어 임시로 빌려 쓰는 어셔(NPC) 스프라이트를 그대로 쓰고 있어서 같은 한계를 그대로 물려받음
- **처리**: 코드로 고칠 수 있는 문제가 아니라(없는 그림을 임의로 만들 수 없음, assets 폴더는 읽기 전용) 수정하지 않음. 사용자가 좌/우 전용 정지 프레임을 직접 추가로 그리기로 결정. `player.gd`의 `IDLE_FRAME` 위에 TODO 주석 추가(새 프레임 그려지면 `Vector2i(-1,0)`/`Vector2i(1,0)` 인덱스를 새 번호로 교체하라는 안내)

## 4. 사용자가 직접 해야 하는 것

- **좌/우 정지 프레임 그림 추가** - 다 그려지면 알려주면 코드 인덱스 교체
- **흙 발소리 에셋 탐색** - 마음에 드는 거 찾으면 Path에 연결
- **직접 플레이 테스트**: 발소리가 걸음 박자에 맞게 나는지, Path/Ground 경계에서 이제 안 이상한지, 정지 시 바로 끊기는지, 연못 소리 원본 볼륨이 다른 소리(브금/비/파도) 대비 너무 튀지는 않는지
- day1~6부터 이월된 콘텐츠 항목(NPC 잡담 대사·이메일 본문 등), 이메일 자동발송 로직 재설계는 계속 미해결(상점 가격/선물 카탈로그는 오늘 확인 결과 이미 완료된 상태였음)
