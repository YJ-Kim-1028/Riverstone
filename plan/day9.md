# Day 9 개발 현황 정리

`day8.md`에 이어지는 문서. 책(도감) 시스템, 아이템 우클릭 사용, 자유 배치형 보관 상자, 타이틀·캐릭터 생성 화면, 캐릭터 색상 커스터마이징을 다뤘고, 같은 날짜에 이어진 두 번의 후속 세션(캐릭터 외형 인게임 연결, GameNew 성능 파일럿)까지 함께 기록한다.

## 1. day9 세션에 완료한 것

- **책(도감) 시스템**: `data/books/books.json` + `BookManager` + `book_screen` 신규. 좌/우 펼침 페이지 레이아웃. 예시 1개만 채우고 나머지는 `data/books/README.md`에 TODO.
- **아이템 우클릭 "사용"**: 인벤토리/장비 탭 양쪽 배선, 죽은 코드였던 I키 인벤토리 화면 삭제, 레시피 아이템 스택 불가 버그(`stack_limit` 아이템별 오버라이드로 수정), 정렬/버리기 버튼 아이콘화.
- **도감 버그 2건**: 아이템으로 배운 레시피 미반영(`CollectionManager`가 `recipe_learned` 신호 누락 구독 → 수정), 도감 툴팁 위치/미표시 버그(3배 확대 구조를 못 잡던 내장 툴팁 → 직접 만든 툴팁으로 교체).
- **보관 상자 시스템 신규**: `StorageBoxManager`, 손에 들고 마우스로 자유 설치(스타듀 스타일), 상자당 24칸, 여닫는 연출. 부수 버그 4건(구매 개수 판정, 장비 스택 오판정, 드래그로 못 빼던 것, 버리기 실패음 중복) 수정.
- **타이틀 + 캐릭터 생성 화면 신규**: 시작하기/이어하기/언어/종료, 슬롯 선택, 캐릭터 생성(이름+외형+미리보기). `project.godot` 시작 씬 변경.
- **캐릭터 색상 커스터마이징**: 여러 차례 재설계 끝에 피부/눈동자/뺨/머리 3톤/상의/하의/신발/장신구(총 10개) 전부 색상환+스와치탭 방식으로 통일. 머리/옷/장신구는 "한 시트에 스타일별 한 줄" 구조로 통일. 스와치 버튼 `flat=true`로 인해 평소 상태가 안 그려지던 버그 발견 및 수정(사용자 스크린샷으로 확인).
- **치명적 버그 수정**: 타이틀/캐릭터생성 화면에 머무는 동안에도 `TimeManager`가 계속 흐르던 문제 → 실제 게임 시작 전까지 게이팅(`play_time_seconds`도 동일 처리).
- **기타**: `randomize()` 누락으로 무작위 로직이 매번 같은 결과만 내던 버그 수정, 타이틀 화면에서부터 빗소리 나던 버그 수정, 1일차 비 안 오게 확정, 새 게임이 기존 세이브를 덮어쓰던 문제 방지(슬롯 삭제 버튼 추가).

## 7. 후속 세션: GameNew 성능 파일럿 (2026-08-08)

되돌릴 수단 없이 실험하는 게 위험해서 `Game`을 복사한 `GameNew`에서만 진행(`Game`은 전혀 안 건드림). `git init` 후 단계별 커밋으로 롤백 지점 확보.

- **타일 렌더링 전환**: "성능 점검(타일 개별 Sprite2D 구조 스케일 한계)" 항목 완료 - 20개 맵 전부 Sprite2D → TileMapLayer(`assets/tilesets/<map_id>_tileset.tres` 맵마다 생성). `TILE_SET_RESOURCES`에 등록 안 된 맵은 자동으로 예전 방식 유지되는 구조라 파일럿(홈맵)→전체 확장이 안전했음. 충돌/물/농사/발소리/경로탐색/조명 로직은 원래 렌더링과 무관해서 안 건드림. 검증: GID↔셀 1:1 일치, 충돌 불일치 0건, 스크린샷 비교(홈맵 전/후, plaza2, cowshed_interior) 전부 동일.
- **부팅 페이드 추가**: 타이틀→메인 전환 시 무거운 씬 인스턴싱이 노출되던 것을 페이드로 가림(`title_screen.gd` + `main.tscn`의 `TransitionLayer/Fade` 기본값 조정).
- **"로딩 후 첫 이동 시 정지" 원인 규명 및 수정**: 실제로는 이동과 무관 - NPC 스케줄 엔진이 첫 "분" 틱에 모든 NPC의 이동시간을 미리 계산하면서, 거리 하나 재려고 안 보이는 맵을 텍스처까지 통째로 렌더링(한 프레임에 38회, plaza1만 7회 - 약 700ms 정지). `WorldMap.load_map()`에 `render` 플래그를 추가해 텍스처/노드 생성을 생략하고 충돌·경로 데이터만 만들도록 수정, 맵별 캐시도 추가. 반환값이 수정 전과 정확히 일치함을 확인. **결과: 700ms → 85ms.** 완전히 0으로 만들려면(백그라운드 워밍업 등) 더 큰 구조 변경 필요해서 보류.
- **정리**: 정체 불명이던 `GameNew/Game` 하위 폴더(중복된 project.godot/CLAUDE.md + 임포트 캐시뿐, 실제 콘텐츠 없음, 프로젝트 어디서도 참조 안 됨 확인) 삭제.
