## 사냥 시스템 - 오늘 처음부터 구현

- 토끼(추격형)/새(은신형) 두 종류, plaza6 HuntZone 안에서 스폰
- 낚시처럼 UI 팝업 여는 대신 맵 위에서 직접 진행 - 다가가서 E로 조준 바(플레이어
  머리 위에 표시) 띄우고, 마커가 강조 구간에 있을 때 다시 E로 포획
- 사냥용 소총(라마가 호감도 50에 선물)을 장착해야만 조준 가능
- 튜닝을 여러 번 반복함(사용자가 실시간 플레이하면서 계속 피드백) - 최종 값:
  - 토끼: DETECTION_RADIUS 40 / STOP_FLEEING_RADIUS 80 / FLEE_SPEED 100(플레이어
    2배) / 미니게임 MARKER_PERIOD 0.6초 / SWEET_SPOT_WIDTH 0.15 (새보다 미니게임이
    더 빡빡함 - "새보다 토끼가 더 어려웠으면 좋겠어" 반영)
  - 새: STARTLE_RADIUS 40 / GRACE_SECONDS 0(놀라면 즉시 도망, 유예 없음 - 사용자가
    명시적으로 이 값 유지를 지시함, 임의로 바꾸지 말 것) / 미니게임 MARKER_PERIOD
    0.85초 / SWEET_SPOT_WIDTH 0.2
  - 공통: CATCH_RADIUS 45(감지 반경보다 5px 넓어서, 눈치채기 직전 짧은 구간에서만
    조준 가능) / 도망 중엔 조준 자체가 안 됨(is_fleeing() 게이팅)
- 버그 두 건 발견·수정: (1) 세이브에 spawned_today 플래그가 저장돼 재시작하면
  스폰이 영구히 막히던 문제 - load 시 이 값을 복원하지 않도록 수정. (2) 새가
  스스로 놀라서 날아갈 때 HuntingManager를 거치지 않고 자기 혼자 queue_free()해서
  죽은 참조가 _active_animals에 남아 개체수 카운트가 부풀려지던 문제 -
  report_self_escaped()로 정리하도록 수정
- 토끼 도망 이동은 존(zone_rect) 안으로만 clamp, 코너에 몰리면 0.4초 동안 무조건
  존 중심으로 커밋해서 달아나는 "복구 모드" 추가(매 프레임 재판단 방식은
  지그재그로 거의 안 움직이는 것처럼 보이는 문제가 있어서 폐기)
- 놓쳐도(타임아웃 포함) 30초 뒤 무작위로 토끼/새 하나가 리스폰(존 안 5마리
  미만일 때만)
