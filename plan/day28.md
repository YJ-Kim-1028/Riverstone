## Stable Audio 유료 구독 - 브금 전면 재생성

- 사용자가 Stable Audio Solo 플랜($12/mo) 1개월 구독 - 상업적 이용 라이선스
  확인 후 결정(연 매출 100만 달러 미만은 유료 플랜에 상업 이용 권한 포함,
  무료 플랜은 비상업용만 가능).
- 프롬프트 여러 라운드 시행착오 - 매번 "이론상 이게 맞다"고 자신 있게
  고쳐준 게 오히려 결과를 나쁘게 만든 적 많았음(사용자 피드백: "너가
  주는건 다 별로냐 왜") - 이후로는 원본 프롬프트를 최대한 유지하고 문제된
  부분만 최소 수정하는 방식으로 전환.
  - 마을/시골 테마 → "Cute RPG" 태그가 오히려 스듀밸리 특유의 "기타가
    리드 멜로디를 이끄는" 느낌을 없앴음, "acoustic guitar as lead" +
    "simple repeating melodic phrase"로 복구 후 이 트랙은 **레스토랑
    브금**으로 최종 배정.
  - 시티팝(어셔 상점 주크박스 판매곡) - "Loopable" 단어 자체보다 옆에
    붙은 "minimal melody/sparse" 문구가 단조로움의 실제 원인이었을
    가능성이 높음(추측, 검증 못 함).
  - 칩튠(주크박스 판매곡, 타이쿤 느낌 요청) - "Cute RPG"를 "tycoon
    management game"으로 바꾸니 이번엔 "bouncy arpeggiated/busy" 문구
    때문에 너무 시끄럽고 음수 과다 → "steady mid-tempo/moderate note
    density"로 재조정.
  - 공포 브금(오르골) - "music box melody" 자체가 실제 오르골처럼
    짧게 반복되는 게 장르 특성상 정상 결과일 가능성 큼(문제가 아닐 수
    있음) - 배경에 서서히 변하는 dark ambient drone 레이어만 추가 제안.
  - 새 마을/필드 테마(별도, farm-life folk) - 템포 미지정 → 65-75 BPM
    추가, "음이 조잡함" 피드백 → "simple clean arrangement, minimal
    ornamentation" 추가.
- **assets/audio/bgm/의 기존 16개 mp3(+.import) 전부 `_old` 접미사로
  git mv 완료**(CLAUDE.md 자산 교체 관례) → 사용자가 새로 뽑은 16개 파일을
  원래 이름 그대로 채워넣음 - 1차 확인 시 `bgm_acoustic_pop.mp3` 하나
  누락됐던 것 발견, 이후 채워서 16개 전부 확인 완료.
- `data/jukebox/songs.json`의 `bgm_path`는 원래 파일명을 그대로 가리키고
  있어서 코드/JSON 수정 없이 새 파일이 바로 적용됨(구조 그대로 유지).

## itch.io 출시 준비 논의

### 확인 결과 - 메모리가 낡아서 실제 상태와 달랐던 것들
- **번역**: 예전 메모리엔 "3명만 ja/zh 완료"였는데, 실제로 확인하니
  13명 전부 en/ja/zh 다 있음(다음 세션 어딘가에서 완료됐는데 메모리
  갱신이 안 됐던 것) - 메모리 정정 완료.
- **하트 이벤트(heart_event_30) 스폰 포인트**: 예전 메모리엔 "24개 중
  0개 배치"였는데, 실제로 plaza2/plaza3 및 카페/서점/가구점/병원/신전 등
  10개 맵 파일에 걸쳐 `<id>_heart_npc`/`<id>_heart_player` 이름으로 이미
  다 배치되어 있었음 - 메모리 정정 완료.
- **골든 도구**: 사용자 확인 - 이미 구현 완료(9개 스크립트에 golden 관련
  로직 존재, farming_manager/fishing_manager/npc_manager 등).
- **print() 디버그 로그**: `footprint(...)`가 전부 "print("를 포함해서
  grep이 30개로 잘못 셌던 것 - 실제 순수 `print()`는 main.gd의
  `_update_ui_blocking()` 로그 딱 1개뿐이고, 이건 CLAUDE.md에 "지우지
  말 것"(2026-08-30 사용자 지시)으로 명시된 것이라 지울 게 없음으로 결론.
- **플레이어 백스토리**: 사용자가 "안 하는 걸로" 최종 확정(콘텐츠 제작
  안 함, 백로그 종료).

### AI 생성 콘텐츠 공개 의무
- itch.io는 업로드 시 AI 생성 콘텐츠 여부를 명시해야 함(그래픽/사운드/
  텍스트/코드 항목별) - 미공개 시 일정 유예기간 후 브라우즈 노출 제외.
  이 게임은 브금이 Stable Audio 생성이라 "Sounds" 항목 체크 필요.
- Steam도 동일하게 AI 콘텐츠 공개 의무 있음(참고).

### 유통 플랫폼 후보
- **해외**: itch.io(진입장벽 없음) + Game Jolt(itch급 진입장벽, SNS성
  기능 있음) 동시 시작 추천. Steam은 $100 등록비+마케팅 부담 커서
  나중 단계. GOG/Epic은 큐레이션이라 첫 작품엔 우선순위 낮음.
- **국내**: 스토브인디(STOVE INDIE, 스마일게이트) - 국내 유일 인디게임
  전문 플랫폼, 크라우드펀딩/퍼블리싱/마케팅 지원까지 포함. 부산인디커넥트
  페스티벌(BIC) 같은 행사도 노출용으로 고려해볼 만함(플랫폼은 아님).

### 게임 제목 - 미확정
- 현재 `project.godot`엔 "Riverstone"(가제 느낌이라 사용자가 불만족).
- 여러 방향 논의했으나 확정 못 함:
  - 지명형(두 단어) 후보들: Nightshade Hollow/Creek(독초+농작물 이중
    의미로 가장 유력했음), Stillwater Hollow, Keepsake Hollow 등.
  - "킬링타임타운"(한국어 언어유희, "킬링타임"의 관용구적 의미) - 영문
    타이틀로 옮기면 스포일러성이 되살아나서(itch.io 주 타겟이 영어권)
    보류. 한국어 전용 제목으로만 쓰는 건 가능.
  - "Slice of Life"(사람 사는 이야기 관용구 + 나중에 "베다"로 이중
    해석되는 가능성) 제안했으나 반응 미온적.
  - 레스토랑 경영/타이쿤 느낌을 담을 방법을 못 찾음 - 장르가 너무
    많아서(농사+축산+낚시+레스토랑+연애+미스터리) 제목 하나에 다 담는 걸
    포기하고 스토어 설명/태그로 나머지 장르를 알리는 방향으로 정리.
- 커버 이미지는 제목 텍스트 없이 아트워크만 먼저 만들고, 제목 정해지면
  텍스트만 나중에 얹는 방향으로 합의(제목 미정이 커버 제작을 막지 않게).
