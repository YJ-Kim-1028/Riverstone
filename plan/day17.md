# Day 17

day16 세션에서 이어짐 - "초반에 할 게 없다" 문제 완화용 요청함(퀘스트) 시스템 신규 작업.

## 이번 세션 진행 내용

- **요청함(퀘스트) 시스템 신규 구현** - 컴퓨터 메일함에 수신함/발신함/초대내역과 분리된 탭 추가
  - 고정 요청(기한 없음): 감자/옥수수/상추 수확, 돼지고기/소고기 획득(발신자 셰퍼드 - 벨제는 비건이라 교체), 고등어/연어/오징어 낚시, 요리 서빙, 마을 사람 13명과 인사하기(폴리), 낚싯대 장만(로시), 마르의 수입 요청
  - 반복 요청: 2~3일마다 NPC 2명이 선호 재료 배달 요청, 완료 시 인벤토리에서 실제 소모, 4일 기한
  - 가구 배달 요청: 10일차 이후 매일 낮은 확률(12%)로 랜덤 가구, 4일 기한
  - 완료 시 보상(골드/아이템) + **발신자 호감도 +3** (선물/메일과 동일 값)
- **추억의 물건 마일스톤 놓침 방지 안전장치** - 호감도 100 대사가 대화로 3일 이상 안 소비되면 그 NPC가 "줄 게 있다" 메일을 1회 발송 (13명 전원 전용 대사)
- **도감 완성 보상: "영혼의 결정" 부활 시스템 구현 완료** (설계는 `.claude/plans/tidy-bouncing-pebble.md` 참고) - 추억의 물건 13개 + 엔딩 3종 중 하나(어느 쪽이 먼저든 상관없음)를 만족하면 영혼의 결정 지급(별도 컷신 연출), 신사 제단(soul_altar, 신규 Interactable)에 바치면 세이지가 나타나는 컷신 후 죽은 피해자(스토커 제외, 최대 3명 - 스토커 살해 2명 + 직접 독살한 무고한 NPC) 중 하나를 골라 부활. 부활하면 가게/메일 자동 재개(실시간 is_alive() 계산이라 별도 처리 불필요), 호감도/이벤트 완전 리셋. 신규: `revival_manager.gd`(오토로드), `NPCManager.revive_npc()`, `scripts/ui/revival_altar_screen.gd`+tscn, `data/horror/revival.json`, `data/items/items.json`의 `soul_crystal`. 헤드리스 컴파일+풀부팅 확인 완료.
  - **재설계 완료** (사용자 지시, 2026-08-25 세션 후반) - 지급 연출을 암전 내레이션 대신 실제 컷신으로 교체: 취침/기절 페이드아웃 직후 plaza5로 잠깐 이동해 영혼(`assets/img/sage_altar.png`, 사용자 제공)이 신사 밖(`shrine_exit` 스폰)에서 하늘로 날아오르는 장면 → 다시 원래 맵(집/병원)으로 복귀 → 페이드인 → 잠든/기절한 플레이어 가슴팍으로 스며드는 장면 → 그 시점에 인벤토리 지급. 제단 상호작용은 세이지 등장 없이 효과음(SFX_MEMORY 임시 재사용)+화면 깜빡임+나레이션 한 줄("이 영혼을 통해...")로 단순화. 영혼의 결정을 인벤에 든 채 세이지에게 말 걸면 1회성 설명 대사("이건... 마을 사람들의 고귀한 영혼이야...") 추가(`npc_manager.gd`의 `get_daily_dialogue()`). `soul_altar`/`sage_altar_spot` Tiled 오브젝트는 사용자가 이미 shrine_interior.tmx에 배치 완료(단, `sage_altar_spot`은 세이지 등장 연출이 빠지면서 현재 미사용).
  - **남은 것 (기획자 작업)**: `soul_crystal` 인벤토리 아이콘(현재 Tools.png 임시 사용), 비행/스며듦 애니메이션 거리·속도 감각 조정(현재 코드 상 임의값), "슈웅" 효과음 전용 파일(현재 SFX_MEMORY 임시 재사용)
  - 디버그 F6: 영혼의 결정 강제 지급(제단 흐름만 테스트, 지급 컷신은 건너뜀)

## 세션 후반 진행 내용 (부활 시스템 재설계 이후)

- **부활 시스템 UI 재설계** - 커스텀 팝업(`revival_altar_screen.gd`+tscn)을 완전히 삭제하고, 기존 NPC 대화창(`dialogue_screen.gd`)에 `dynamic_choice` 타입(런타임 옵션 생성 + 콜백)을 새로 추가해 재활용. 제단 상호작용 → 되살릴 대상 선택 → 확인 단계까지 전부 하단 대사창 하나로 처리(사용자 지시 - "npc와 대화할 때처럼 하단에 고정된 부분에서").
- **한글 조사 자동 처리 시스템** - `NPCManager.apply_korean_particles()` 신규(받침 유무로 이/가·은/는·을/를 자동 선택). `{victim_name}`/`{player_name}` 치환하는 3곳(npc_manager, dialogue_screen, horror_event_manager)에 전부 적용. 기존 ~14개 데이터 파일에 하드코딩된 조사가 이름에 따라 문법이 깨지는 문제(예: "셰퍼드이") 해결 - 데이터는 안 건드리고 치환 엔진에서 처리.
- **디버그 단축키 전면 구축** (F1~F12 전부 사용 중, `OS.is_debug_build()` 가드) - 매번 실제 플레이로 스토리 진행시키지 않고 각 컷신을 바로 테스트하기 위함
  - F1: 전원 호감도 30 / **Shift+F1**: 전원 호감도 100 (스토리 NPC/스토커 포함)
  - F2: `MurderManager.debug_force_commit_murder()` - 실제 살인 경로 그대로 타서 알리바이/사칭메일 등 후속 시스템 다 작동 (1회차=발견 씬 자동재생, 2회차=집에 자루 등장)
  - F3/F5/F8: 진실/공범/체포 엔딩 강제 트리거, F6: 영혼의 결정 강제 지급, F7: 원시 강제사망(정식 살인 케이스 기록 없이 즉사 - 알리바이/그리프 대사 등 후속 시스템은 안 탐, F2와 용도 구분해서 유지), F4(기존): 살인 후보 큐잉용 호감도 120 일괄
- **호감도 30/100 이벤트 대규모 폴리싱** (실제 플레이 테스트 중 연속 리포트 대응)
  - `player.walk_to(target, run)`에 run 파라미터 추가 - 컷신 중 자동 이동이 항상 전력질주였던 걸 상황별로 구분(살인 발견/체포 엔딩은 그대로 빠르게, 호감도 이벤트는 평소 걸음으로)
  - 30 이벤트 도착 시 NPC 쪽 정면을 보고 1초 정지(`_settle_after_heart_event_arrival`) - JSON `player_facing` 필드로 개별 이벤트가 기본값(NPC 바라보기)을 덮어쓸 수 있음(플로라/벨제=뒷모습 "up", 마린=옆모습 "left")
  - 벨제/플로라/마린처럼 다른 맵으로 나가는 30 이벤트에 `entry_spawn`(원래 나오던 워프 자리) 필드 추가 - 순간이동 대신 그 자리부터 걸어오는 연출
  - 30 이벤트 사각지대 수정: 기존엔 "맵에 새로 들어오는 순간"에만 조건 검사(`_prepare_heart_event`)해서, 이미 그 방에 서 있는 동안 조건이 충족되면 나갔다 들어오기 전까진 영영 트리거 안 됨 → 100 이벤트처럼 매 프레임 재확인하는 `_maybe_trigger_live_heart_event()` 추가
  - 30 이벤트 중 선물 지급형(`{"type":"gift"}` - 우디/모카/로시/이샤/마르)이 인벤토리 꽉 찬 상태에서 발동되면 아이템이 조용히 증발하던 버그 수정 - 발동 조건에 인벤토리 여유 체크 추가(추억의 물건과 동일 패턴)
  - 30/100 이벤트 페이드를 전역(0.2초)보다 긴 전용 값(0.6초)으로 분리 - "이벤트 느낌" 강화
  - **100 이벤트 NPC 접근 애니메이션이 멈춰 있던 버그 수정** - `NPCSprite._process()`가 시간 정지 중엔 걷기를 멈추는데, 100 이벤트 자체가 시작하자마자 시간을 멈춰서 정작 "다가와" 걸음까지 얼어붙었던 것(컷신 끝나고 시간이 풀리는 순간에야 순간이동처럼 옆에 나타남). `walk_npc_to_position()`이 이 한 걸음만 시간정지를 무시하도록 예외 플래그(`set_ignore_time_pause`) 추가
  - 마린 100 이벤트 전용: 다가오는 동안 축구공(`memento_marin` 아이콘 재사용) 이미지가 플레이어↔마린 사이를 반복 왕복하는 연출 추가(새 에셋 없이 Sprite2D+Tween)
  - 이속 버프 두 개가 겹칠 때(세이지 행운 버프 20% 중 아메리카노 10%) 약한 쪽이 강한 쪽을 덮어써서 오히려 손해였던 버그 수정 - 버프끼리는 더 강한 쪽 유지, 디버프는 기존처럼 항상 덮어씀
  - 밸런스: 아메리카노 이속 버프 10%→30%, 세이지 행운 버프 10%→20%(디버프 -10%→-20%와 동일 폭)
  - 메일 상세보기 패널 스크롤바가 본문 글자를 가리던 문제 수정(수신함 목록과 동일한 여백 컨테이너 방식)
  - **미해결**: 우디의 30 이벤트가 정상 순서(호감도 30 채운 뒤 맵 진입)로도 발동 안 된다는 리포트 - 위 사각지대/인벤토리 버그를 고쳤지만 "아예 발동 안 됨" 자체의 확정 원인은 못 찾음. 재확인 필요(오래된 세이브의 `has_shown_heart_event` 잔존 가능성도 의심).
