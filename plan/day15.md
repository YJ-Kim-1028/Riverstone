## 3. 이번 세션 진행 내용 (2026-08-24)

- **2차 살인 발견 씬 신규**: 1차(비명 → plaza3까지 강제로 뛰어감)와 다르게, 시체가 플레이어 집(Home) 앞에 놓이고 나중에 직접 돌아왔을 때 발견하는 방식으로 분리(`_spawn_second_murder_sack()`가 자루만 먼저 세워두고, E로 상호작용해야 `_continue_second_murder_discovery()`가 독백→폴리 등장→강제 대화로 이어짐). 살인 조건도 정정: 스토커와 피해자가 같은 맵에 있어도 되고(플레이어 시야에 둘 다 없으면 됨), 최소 14일 쿨다운 추가. 2차 전용 콘텐츠: `murder_grief_2`(어종·NPC별 새 대사, "기억 까먹음" 장치 재사용 안 함 - 세이지는 죄책감/무력감 톤으로, 마린/로시는 서로가 피해자일 가능성을 배려해 상대 이름 직접 언급 안 함), 폴리의 `second_murder_discovery` 대사(플레이어가 직접 신고했다는 전제), `{victim_name}` 치환 재사용(중복 함수 만들 뻔했다가 기존 `NPCManager.get_most_recent_death_npc_id()`로 정리), `impersonation_emails.json`의 `default_2`는 사용자가 직접 채우기로 하고 TODO만 남김.
- **효과음 다수 배선**: 대화 타이핑/넘김(`sfx_dialogue_type`/`_advance`, `dialogue_screen.gd`에 타자기 효과 신규), 집 강화 구매(`sfx_home`, 기존 동전 소리와 분기), 스토커 메일 열람(`sfx_stalker_mail`, 일반 메일은 `sfx_mail_open`), 살인 발견 씬들(`sfx_murder_1`=1차 plaza3 도착, `sfx_find_body_2`=2차 자루 확인+레스토랑 액자+낚시 물귀신까지 공용 스팅으로 재사용).
- **레스토랑 액자 핏자국 연출**: 하드코딩 좌표 → Tiled `EffectArea` 레이어(신규, 사각형 오브젝트) 기반으로 변경, 절차적 셰이더(사용자 피드백 "피피티 클립아트 같다")는 폐기하고 `CanvasItemMaterial(BLEND_MODE_MUL)`로 실제 액자 그림을 붉게 곱연산 틴트하는 방식으로 교체. 맵 이동해도 안 사라지던 버그는 `_load_map()` 시작부에서 트윈 강제 kill+visible=false로 수정.
- **버그 수정 2건**: `event_invite` 메일이 초대 안 한 방문객에게도 발송되던 것 - 방문자 전체 목록 대신 `RestaurantManager.get_todays_invited_npc_id()`(신규)로 특정. 장비창에 인벤토리창과 달리 hover 툴팁이 없던 것 - `equipment_slot.gd`에 동일 패턴 추가.
- **낚시(plaza3) 완전 불통 버그**: 해안 타일에 육지/바다 사이 전환 버퍼가 껴 있어 바로 앞 1칸만 보면 안 닿는 게 원인. 정면 1칸 → (바다 전용) 대각선 이웃 2곳 + 정면 2칸째까지 허용하는 것으로 확장(연못/강까지 열어주면 너무 멀리서도 낚시가 된다는 지적으로 "Water" 레이어 전용 `is_sea_cell()` 신규 분리). 오징어 난이도(사용자가 직접 지정했던 값)가 "개어렵다"는 피드백으로 완화(hits 7→6, appear/hide 0.4/0.6→0.45/0.55).
- **낚시 물귀신 이벤트 재작업**: 원래 미니게임 UI가 잠깐 열렸다 "...아무것도 없다" 텍스트만 뜨는 게 임팩트 없다는 지적으로 전면 교체 - UI 자체를 안 열고(`FishingManager.is_ghost_bite()`를 보고 `fishing_screen.gd`가 스스로 오픈 스킵), 물고기 등장 효과음을 0.12초 간격으로 1.3초간 반복 재생해 씨름하는 느낌을 준 뒤 뚝 끊고 호러 스팅+독백("무언가가 낚시대를 거세게 잡아당겼다." / "그러나 낚시대엔 아무것도 없다.", 사용자 확정 문구)으로 마무리.
- **`dialogue_screen` 초상화 레이아웃 버그**: `open_special("", ...)`(NPC 없는 혼잣말)일 때 초상화 텍스처가 없어도 칸이 빈 채로 남아 어색했던 것 - npc_id가 비어있으면 초상화를 숨기고 텍스트 영역을 그 자리까지 당겨서 채우도록 수정.
- **노크 이벤트 다듬기**: 발동 시각을 22시(`TimeManager.NIGHT_EVENT_HOUR`, 노크 전용 소비처)에서 21시로 조정. 소리를 사용자가 새로 구해서 2번 교체(`.m4a`는 Godot가 임포트 못 하는 포맷이라 반려 → `sfx_knock2.mp3`로 최종). 재생 횟수 3→1(새 소리 자체가 이미 세 번 두드리는 소리라 중복이었음), 재생 중엔 `AudioManager.is_knock_playing()`을 보고 이동을 잠가서 문 앞으로 뛰쳐나갈 수 없게 함. F10 디버그 트리거 추가(처음 F8로 넣었다가 Godot 에디터 "실행 중지" 기본 단축키와 겹쳐서 충돌 - F10으로 교체). 소리가 끝나면 혼잣말("방금 무슨 소리지?" / "나가서 확인해볼까...?") → 실제로 문 열고 나가면(`home_interior`→`Home`, 직전 맵까지 확인) "...아무도 없다." 반응 1회. 그날 밤 안 나가고 자거나 기절해서 병원에 실려가면 다음날 뜬금없이 뜨는 게 어색하다는 지적으로, `TimeManager.day_changed`에 걸어서 날짜가 바뀌면 그 밤의 "확인 대기" 자체를 리셋하도록 함.
- **정체 불명 그림자 인영 신규**: 발소리/물건 옮김/거울 반사 등 여러 호러 연출 후보를 논의하다("쯔꾸르 게임" 클래식 장치들 참고) "멀리서 서 있다가 다가가면 사라지는 인영"으로 확정. 1차 살인 이후 & 스토커 생존 중일 때만(스토커 사망 시 자동 종료 - "3차 전에 스토커는 죽게 되어있으니까"라는 사용자 지적을 그대로 조건화) 사용자가 Tiled에 직접 찍은 스폰 지점(Home/plaza1/plaza4/plaza5, `shadow_figure_<map>`)에 20% 확률로 등장, 플레이어가 4칸 안으로 다가가면 사라짐(처음엔 부딪히기 직전 거리였다가 "너무 가까워야 사라진다"는 지적으로 조정 - 320x180 해상도에서 4칸이면 화면 밖으로 안 잘리고 사라지는 것까지 보임을 계산으로 확인). 스토커인지 귀신인지 정체는 끝까지 확정하지 않기로 함(사용자 지시) - 처음엔 실존 NPC 스프라이트를 검게 물들여 재사용했으나 체형/머리 모양으로 성별이 드러날 수 있다는 지적으로, 전용 그림 한 장(`assets/img/shadow_figure.png`, 16x32, 정면만) 방식으로 교체 - 파일은 아직 사용자가 그려서 넣을 예정, 없는 동안은 이벤트가 조용히 스킵됨.
