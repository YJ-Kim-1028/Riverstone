# Day15 세션 변경사항 테스트 케이스

오늘(2026-08-24) 세션에서 건드린 것들 테스트용 체크리스트. 항목별로 체크하면서 진행하시면 됩니다.

## 0. 사전 준비

**디버그 키(F키, 디버그 빌드에서만 동작)**
- `F4` — 살아있는 일반 NPC 전원의 호감도를 살인 후보 기준(120)으로 즉시 세팅 (3번째 살인 후보/체포 엔딩 테스트용)
- `F9` — 테스트용 재료 지급
- `F7` — 테스트용 보관함 지급
- `F10` — 노크 이벤트 강제 발동
- `F12` — 레스토랑 액자 핏자국 트리거 리셋
- `F11` — 전체화면 토글

**주의할 점**
- 살인 조건(비/오후10시/맵 분리)은 **비를 강제로 트리거하는 디버그 키가 없어요.** 자연스럽게 비 오는 날까지 기다리거나, 저장해두고 하루씩 넘기면서 확인하셔야 합니다. 필요하면 말씀해주시면 디버그용 강제 비 키 하나 추가해드릴게요.
- 각 엔딩은 세이브 슬롯 하나를 "엔딩 직전" 상태로 미리 만들어두고 슬롯 복사/백업해두면, 엔딩 3종을 각각 반복 테스트하기 편합니다.

## 1. 상점 승계 버그 픽스 (`npc_manager.gd`)

방금 고친 부분 - 주 운영자(벨제/마린)와 보조(셰퍼드/로시)가 뒤바뀌어 상점이 비어버리던 문제.

- [ ] 셰퍼드만 죽이기 → 벨제가 원래 스케줄(`pasture_working`) 그대로 유지, 목장에 벨제가 정상적으로 서있는지
- [ ] 로시만 죽이기 → 마린이 원래 스케줄(`fish_working`) 그대로 유지, 낚시가게에 마린이 정상적으로 서있는지
- [ ] 벨제만 죽이기 → 셰퍼드가 벨제 스케줄로 갈아타서 목장에 실제로 나와있는지
- [ ] 마린만 죽이기 → 로시가 마린 스케줄로 갈아타서 낚시가게에 나와있는지
- [ ] 벨제+셰퍼드 둘 다 죽이기 → 목장 문이 잠기고(`문이 굳게 잠겨 있다`), 컴퓨터 온라인 상점 목록에 뜨는지
- [ ] 로시+마린 둘 다 죽이기 → 낚시가게도 동일하게 온라인 전환되는지

## 2. 2차 살인 이후 콘텐츠

- [ ] **마르 지목 소문**(`suspicion_talk_2`) — 2차 살인 발생 후, 벨제/모카/셰퍼드/어셔/우디/로시/이샤 7명과 대화 시 각자 대사가 뜨는지 (마르 본인도 자기 반응 대사가 있음)
  - [ ] 마르가 이미 죽어있는 경우, 마르 관련 대사(벨제/모카/셰퍼드/어셔/우디/로시)가 조용히 스킵되는지
  - [ ] 이샤는 마르가 아니라 플로라를 지목하는지, 플로라가 죽어있으면 스킵되는지
- [ ] **알리바이 리마인더 메일** — 2차 살인 후 벨제/모카/셰퍼드/어셔 중 3일간 대화 안 한 NPC에게 메일이 오는지 (제목: "무서워서 그런지"/"다들 뒤숭숭하네"/"마음이 편치 않아서"/"나도 무서워서")
  - [ ] 마르가 죽어있으면 이 4명 리마인더 자체가 안 오는지

## 3. 독약 처리

- [ ] 독약 서빙 → **그날 바로 안 죽고**, 다음날 하루가 바뀌는 순간 실제로 사망 처리되는지
- [ ] 세이브하고 재접속해도 "대기 중" 상태가 안 날아가는지 (다음날 되면 정상적으로 이어서 처리됨)

## 4. 진실 엔딩 (스토커 본인 독살)

- [ ] 어셔에게 독약 사용 → 다음날 사망 → 나레이션만 재생되는지
- [ ] 나레이션의 `{victim_name}`이 "어셔"로 정확히 나오는지
- [ ] 컷신 끝나고 평소처럼 자유 플레이 가능한지
- [ ] 어셔 서점이 잠기고 온라인 상점에 뜨는지 (1인 상점이라 바로 전환)

## 5. 공범 엔딩 (무고한 NPC 독살)

전체 순서: 서빙 → 다음날 사망 → 발견+마을반응(폴리) → (페이드) 체포→위증→폴리반응→석방 → 시간경과 → home_interior 이동 → 메일 확인 → 노크 → 문 앞 E → 어셔 이사 → 마무리

- [ ] 무고한 NPC에게 독약 사용 → 다음날 사망 처리
- [ ] 폴리가 반응(`poison_victim_reaction`) — 이 대사가 사실상 체포 트리거 역할도 겸함
- [ ] 어셔 위증(`accomplice_testimony`) → 폴리 반응(`accomplice_release`) → 석방
- [ ] home_interior로 강제 이동 후 **스토커 메일 도착 + 알림음**
- [ ] 메일 열람 → **60초간 강제로 못 닫히는지**(뒤로가기/닫기/ESC 다 막히는지) 직접 눌러보고 확인
- [ ] 60초 지나면 자동으로 컴퓨터 창 닫히는지
- [ ] 노크 소리 재생 중엔 이동 불가한지
- [ ] 노크 끝난 뒤 문 앞에서 E 누르면 이사 컷신으로 이어지는지 (평소처럼 밖으로 안 나가지는지)
- [ ] 어셔 이사(`accomplice_move_in`) → 마무리 나레이션
- [ ] **컷신 중간(메일 대기~어셔 이사 사이)에 게임을 강제 종료했다가 다시 켜보기** — home_interior로 다시 데려다놓고 이어서 재생되는지 (이 부분이 가장 검증 안 된 부분이라 꼭 확인 필요)
- [ ] 엔딩 이후 어셔가 저녁마다(집 레벨과 무관하게) 집으로 "퇴근"하는지 확인
  - [ ] 집 레벨 1/2/3 각각에서 확인 (레벨별로 다른 `home_interior_2.tmx`/`_3.tmx` 파일 로드되므로, 스폰 지점 `usher_home_standing`이 3개 파일 다 찍혀있어야 함)

## 6. 체포 엔딩 (3번째 살해 시도 저지)

**사전 준비**: `book_interior.tmx`에 스폰 지점 4개 필요 — `arrest_scene_player`, `arrest_scene_poli`, `arrest_scene_usher`, `arrest_scene_victim`. 안 찍혀있으면 해당 캐릭터가 그 자리에 안 나타남(에러는 안 남).

- [ ] F4로 NPC 전원 호감도 120 세팅 → 2명 살해 진행 → 3번째 후보 대기 상태에서 살인 조건(비/22시/맵 분리) 충족 확인
- [ ] 경고 사격 소리 재생 확인
- [ ] 지금 있는 아무 맵에서나 트리거해서 book_interior까지 실제로 뛰어가는지(경로가 이상하게 꼬이지 않는지 - 여러 시작 맵에서 테스트)
- [ ] 도착 시 폴리/어셔/살아남은 대상 3명이 각자 스폰 지점에 정상적으로 서있는지
- [ ] 대사 순서: 폴리 경고 → 어셔 마지막 말 → 폴리 반응(미란다 고지 포함) 확인
- [ ] 대사 끝나자마자 총소리 + 즉시 페이드아웃(여운 없이 끊기는지)
- [ ] 나레이션(칼/총) → 나이프 드롭 소리 → 어셔 마지막 유언 대사 → 마무리 나레이션 → 폴리 대사 → 최종 나레이션 순서 확인
- [ ] `{spared_name}`이 실제로 살아남은 NPC 이름으로 정확히 치환되는지
- [ ] 컷신 끝나고 정상적으로 자유 플레이 복귀하는지, 임시로 세웠던 분신들이 잘 사라지는지
- [ ] 어셔 서점 잠기고 온라인 상점 전환되는지
