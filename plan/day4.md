# Day 4 개발 현황 정리

`day3.md`에 이어지는 문서. 이번 세션은 크게 세 덩어리로 이루어졌다: ① NPC가 여러 맵을 거쳐 실제로 "걸어서" 이동하는 시스템 전면 구현, ② NPC와의 일일 대화 기능 신규 구현, ③ 대화창을 만들면서 드러난 폰트 흐림 문제의 원인 규명과 수정(시행착오 포함). 그 사이사이 레스토랑/계산대 관련 버그도 여럿 고쳤다.

---

## 1. 오늘 완료한 것

### 1-1. NPC 멀티홉 이동 시스템 (전면 신규 구현)
- 기존엔 NPC가 스케줄이 바뀌면 인접하지 않은 맵으로도 조용히 순간이동하고 있었다. 모든 맵의 워프(`target_map`/`target_spawn`)로 맵 연결 그래프를 만들고, BFS로 경로를 구해 **경유 맵을 실제로 순서대로 통과하며 걷도록** 전면 재구현(`home_map.gd`의 static 함수들 + `npc_world_manager.gd`의 홉 체인 상태머신).
- 한 맵에 같은 목적지로 가는 워프가 여러 개 있을 때 임의로 고르던 문제 → 워프 자신의 `target_map`/`target_spawn` 데이터로 정확히 특정하도록 수정.
- 맵 연결 그래프가 전부 실제 `target_spawn` 이름으로 완전히 연결된 것을 BFS로 확인한 뒤, "기본 스폰 지점" 폴백(`get_default_spawn_position()`) 개념을 완전히 제거(사용자 확인 후 결정).
- 부수적으로 고친 버그 5개: 임시 맵 인스턴스에서 `_clear_tiles()` 크래시, 오프스크린 이동 타이머가 실시간(OS) 기준이라 가속/일시정지 상황에서 어긋나던 것(게임시간 기준으로 수정), 오프스크린 경로에서 `SPAWN_ALIASES`가 적용 안 되던 것, "이동 중단 후 재개"가 진짜 도중 위치가 아니라 문 앞에서 다시 걷던 것(실제 보간으로 수정), 이동 중 스케줄이 바뀌면 진행 중이던 위치가 날아가던 것(중간 지점 보존 후 재경로 계산).
- **선제적 출발 시각 계산** 추가 — NPC가 스케줄 시각에 "정확히 도착"하도록, 이동 시간을 미리 계산해서 그만큼 일찍 출발하게 함.
- **실제 걷기 애니메이션** 구현 — 스프라이트시트의 실제 10프레임 배치(정지/좌우 걷기 프레임 2종씩/상하)를 반영, 애니메이션 속도를 사용자 피드백대로 천천히 조정.
- NPC 이동속도 40→25로 하향, 4방향 스프라이트에 안 맞던 대각선 이동을 비활성화(`DIAGONAL_MODE_NEVER`).

### 1-2. NPC 물리적 위치 정밀 추적 (신규)
- `NPCManager.get_npc_world_position()`은 스케줄만 보고 즉시 계산하는 값이라, "스케줄상 도착"과 "실제로 걸어서 도착"이 다를 수 있다는 게 드러남 → `NPCWorldManager`가 실제 정착/출발 시점마다 갱신하는 정확한 좌표 추적(`NPCManager.set_npc_physical_spot`/`is_npc_settled_at`)을 새로 추가.
- 계산대(`cash_register`)가 NPC 없이도 사용되던 버그를 이걸로 수정 + "E 사용" 프롬프트 추가(`ShopManager.is_staffed()`).
- 같은 맵 안에서의 이동은 기존에 도착 판정 자체가 없었던 것도 발견해 새로 추가(`_check_same_map_arrivals`).
- 하루가 바뀔 때(취침 후) NPC가 새 스케줄 위치까지 걸어가는 시간차 없이 **즉시 재배치**되도록 수정(`TimeManager.day_changed` → 하드 리셋) — 플레이어가 09시 정각에 가게에 가도 항상 직원이 있도록.

### 1-3. NPC 일일 대화 기능 (신규)
- NPC에게 다가가면 "E 대화" 프롬프트, 하루 1번만 가능(재대화 시도는 프롬프트도 안 뜨고 E도 무반응).
- 대사 선정: 요일×호감도(기존 로직 재사용) + **날씨**(비 오는 날 전용 대사 풀 `rain_conversation` 추가, `horror_conversation`과 동일한 패턴). 실제 대사 문구는 기획자 영역이라 빈 배열 + 자리표시자 텍스트만 넣음.
- 대화창 UI 신규(`dialogue_screen.gd`/`.tscn`) — 초상화 + 이름 + 대사 한 줄씩 넘기기(E), 마지막 줄에서 닫힘.
- 발견/수정한 버그: `TALK_RADIUS`가 타일 인접 거리보다 좁아서 대화가 아예 안 열리던 버그(12→24), 레스토랑 초대 손님이 도중에 쫓겨나면 영구적으로 재방문 불가능하던 버그(`_visited_today` 미초기화), 호감도가 실제로 오르는 시점(서빙 완료)이 아니라 착석 시점에 "오늘 방문"으로 처리되던 것 → 서빙 시점으로 이동.
- **계산대 vs NPC 대화 우선순위 충돌**: `TALK_RADIUS`를 넓히면서 카페처럼 계산대와 NPC가 붙어있는 곳에서 대화가 항상 계산대 사용을 가로막던 문제 → 실제 거리 비교로 더 가까운 쪽 우선하도록 수정, 모달(대화창 등)이 열려있으면 다른 월드 상호작용이 같이 처리되지 않도록 가드 추가(전체 모달 공통 버그였음).

### 1-4. 대화창 폰트 문제 진단/수정 (시행착오 포함)
- 대화창 글자가 흐릿한 원인 조사 → 프로젝트 기본 폰트 `Galmuri11`이 11px 설계 폰트인데 실제로는 2~7px로 축소해서 쓰고 있던 것이 근본 원인으로 확인.
- **실수**: 폰트 import 설정(`antialiasing`/`oversampling`)을 직접 꺼봤다가 HUD 포함 전체 텍스트가 깨지는 심각한 회귀 발생 → 즉시 원복.
- 대신 인터넷창(`mail_app`)이 이미 쓰고 있던 "이중 확대 배율을 서로 상쇄시켜 순 배율 1배로 만들고, 그 안에서 폰트를 원래 크기에 가깝게 그리는" 구조를 대화창에도 적용(`TextArea` wrapper, scale 0.4 vs 바깥 scale 2.5).
- 사용자가 새로 추가한 `GalmuriMono7.ttf`를 시험 적용했다가, 모노스페이스 폰트 특유의 두꺼운 느낌이 HUD랑 안 맞는다는 피드백을 받아 `Galmuri11`로 최종 교체(모노스페이스는 지시 전까지 사용 금지로 기억해둠).
- 대화 내용 칸이 2글자마다 줄바꿈되던 버그 → `VBox`에 `anchor_right`/`anchor_bottom` 설정이 빠져서 폭이 사실상 0으로 계산되던 것이 원인, 수정.
- 그 외: 이름/대사 폰트 크기 축소, 프레임과 화면 하단 사이 여백 추가(pivot 기준점 오류가 원인), 대화 넘김 키(E) 확인용 "E ▶" 힌트 라벨 추가, 플레이스홀더 대사 3줄을 서로 뚜렷이 다른 문장으로 변경, 대화 내용 폰트 크기 최종 7→5로 조정.

### 1-5. 그 외
- `game_design/05_drafts/new_cooking_system.md`를 사용자와의 논의 결과대로 갱신(실제 조리 시간, 완성대=서빙 지점으로 사재기 원천 차단, 조리기구 레스토랑 영업시간 내 사용 제한, 쥐약은 기존 UI 재사용). **구현은 아직 안 함** — 재료-기구 매핑표 등 후속 데이터가 필요.
- `plaza2.tmx`의 벚나무 Y-sort 앵커 2개가 완전히 겹치던 문제 → 폴리곤 앵커는 미지원이라 사용자가 나무 하나를 직접 삭제해 해결.

## 2. 오늘 발견하고 고친 버그 (요약)

- 임시(화면에 안 붙은) 맵 인스턴스에서 `_clear_tiles()` 크래시
- 오프스크린 이동 타이머가 실시간 기준이라 게임 가속/일시정지 때 어긋남
- 오프스크린 경로에서 `SPAWN_ALIASES` 미적용
- 이동 중단 후 재개 시 실제 진행 위치를 무시하고 문 앞에서 다시 걷던 문제
- 이동 중 스케줄 변경 시 진행 중이던 좌표가 날아가던 문제
- 스프라이트 애니메이션이 프레임 하나만 소비해 가속/랙 상황에서 도착이 십수 분 늦어지던 문제
- 계산대가 NPC 부재 시에도 사용 가능하던 문제 (+ "E 사용" 프롬프트 누락)
- 같은 맵 안 이동은 도착 판정 자체가 없던 구조적 공백
- `TALK_RADIUS`가 타일 인접 거리보다 좁아 대화가 아예 안 열리던 문제
- 레스토랑 초대 손님이 쫓겨나면 영구 스킵되던 문제
- 계산대와 NPC 대화 우선순위 충돌(모달 열림 중 다른 상호작용이 같이 처리되던 공통 버그 포함)
- 대화창 `VBox` anchor 누락으로 텍스트 폭이 0에 가깝던 문제
- 대화창 폰트 안티에일리어싱을 잘못 꺼서 전체 텍스트가 깨졌던 회귀(즉시 원복)
